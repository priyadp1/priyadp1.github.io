# priyadp1.github.io

Personal portfolio site for Prisha Priyadarshini, built with Next.js and Tailwind CSS and deployed to GitHub Pages as a static export.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site written to ./out
```

Pushing to `main` builds and deploys the site via `.github/workflows/deploy.yml`.
